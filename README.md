# Хроники Галактики

Личный гид по экранному канону «Звёздных войн»: хронология до каждой серии, отметки просмотра, будущие премьеры, темы-планеты.

## Как устроено

- `index.html` — разметка и стили.
- `js/data.js` — **вся хронология**. Чтобы добавить новый фильм или сезон, допиши объект в массив `D` в нужное место по хронологии.
- `js/trailers.js` — ID трейлеров YouTube.
- `posters/<id>.jpg` — постер (имя файла = `id` из `data.js`).
- `js/sync.js` + `js/supabase-config.js` — синхронизация прогресса через Supabase (вход через GitHub).
- `supabase.sql` — таблица прогресса и правила доступа (каждый видит только свой прогресс).

## Пример новой записи

```js
{id:"ahsoka2",t:"Асока · Сезон 2",o:"Ahsoka",k:"live",era:"nr",y:10,yl:"≈10 ПБЯ",r:"2027-01-20",m:45,
 d:"Описание без спойлеров.",
 eps:`1|Part Nine: ...
2|Part Ten: ...`},
```

`k`: `film` / `live` / `anim` · `y`: год (минус = ДБЯ) · `r`: дата премьеры · `m`: минут.
